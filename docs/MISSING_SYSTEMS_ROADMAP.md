# The Climb Missing Systems Roadmap

This roadmap lists additional systems and experiences that are not part of the current 1.0 feature set. It is written for a premium, faith-based self-improvement product aiming for App Store Editor's Choice quality. Items intentionally avoid duplicating the existing baseline: auth, onboarding, AI daily mission/devotional generation, focus mode, reflection, OVR, streaks, journal, progress charts, community groups, partners, feed, leaderboards, notifications, widgets, and Firebase sync.

Stage key: MVP means add before or soon after launch if possible. V2 means strong retention/product depth. V3 means larger platform, trust, or ecosystem expansion.

## Highest-Leverage Build Order

1. Production trust layer: under-18 privacy tier, moderation reports, blocked user propagation, profanity and self-harm safety, support tickets, feature flags, analytics taxonomy, crash reporting, skeleton and empty states, error recovery.
